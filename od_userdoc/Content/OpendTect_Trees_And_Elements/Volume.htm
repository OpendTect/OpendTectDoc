3.3 Volume

A volume can be added by clicking on Volume element in the tree and selecting Add option. A small volume box with blank attribute is added to the scene. An attribute in the newly inserted volume can be displayed by right clicking on the volume and selecting the Select Attribute option. This works similar to inline/crossline/Zsliceinline/crossline/Zslice.

You can display either the stored volumes or calculate the attribute within the sub-volume. For faster response times, pre-loadpre-load the data you wish to visualize using this tree element.

The pop-up menu for the Volume element resembles that described in the previous section for inline/crossline/Z-sliceinline/crossline/Z-slice:

Select Attribute: Select/change the data in a volume.

Properties: Change display parameters such as transparency and ambiance reflectivity:

Once data has been added to the volume element, right-clicking will pop up other options, including, under 'Display', the 'Create Iso Surface Geobody' - this is a single process which computes arbitrary iso value surfaces and convert them into bodies. These are displayed directly under the tree element 'Geobody'

If the option Display > Create Iso Surface Geobody is selected, the following window pops up with choice of modes:

The window displays the histogram of the data collected within the loaded volume (left), or from seeds only that are stored in a pointset (right). "Update" will update the display in this UI (requires some computation time) while leaving the window open. OK will accept the currently selected (or updated) value and create the corresponding Iso Surface Geobody displaying it under the tree element 'Geobody' with a name consisting of the prefix 'Iso, followed by the user-selected Iso value. The properties of the Iso Surface Geobody are akin to the properties of standard Geobodies, see 3.11 Geobody

In Interact mode, (see Mouse ControlsMouse Controls) the cursor will return the position (inline, cross-line and X,Y,Z) and the data value at that position in the horizontal status bar of the OpendTect window.
