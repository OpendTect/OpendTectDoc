3.10 FaultSet

The FaultSet option allows the user to add Sets of faultsets from storage, selected via a standard object selection window. FaultSets are uneditable objects.

Once a FaultSet is displayed, right-clicking on the main tree element name gives access the other standard tree item options:

Add... Opens the standard selection window to add a FaultSet.

Show all items: It is used to check all items, which means that all items would be displayed in the scene.

Hide all items: It is used to hide all (check out) the displayed faultsets.

Remove all items from Tree: Removes all faultsets that are added in the tree.

 

The (right-click) sub-menus for the displayed FaultSet(s) are explained below:

Add... Opens the standard selection window to add data to the FaultSet.

Display

Histogram: It shows multiple histograms of the displayed data along the selected faultset.

Properties: Set the Material, Texture and Line Style properties.

Only at sections: Toggle on to display a faultset on a section as a stick.

Use single color: It sets a single color to a faultset display.

Lock: Lock the selected object. Prevents accidental removing, moving, or displaying data on object. Click again to unlock.

Remove from Tree: It removes the selected faultset from the scene.

 

The sub-menus for the displayed attributes are explained below:

Select Attribute: It is used to select and display various types of data.

Save Color Settings: The active color tablecolor table could be stored permanently or updated for the displayed stored attribute. For instance, if you do not like the color bar for a particular seismic data (say PSTM) that is Red-white-blue (color table) and you want to change it into Magic, you could set it here. It will save the color settings for this specific stored volume (PSTM).

Use saved Color Settings: Use the saved color settings.

Move: To change the display level of an attribute, it can either be moved up / down or placed to top / bottom.

Display: To make a fault semi-transparent, the transparency is used. One can also visualize the histogram of the attribute.

Remove: It remove the selected attribute from the tree.
