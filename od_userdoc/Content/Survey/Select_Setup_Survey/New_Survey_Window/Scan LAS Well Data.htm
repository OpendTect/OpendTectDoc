4.1.2.8 Scan LAS Well Data

On clicking Next, the following UI appears, allowing selection of the relevant LAS files plus the option to set a Coordinate System (or leave it as unlocated):

Once set, pressing Continue enters the LAS data into the Survey Parameters UI:

Clicking OK here enters the survey into the data root allowing for actual selection.

Select will launch the new survey and offer the user to import the LAS data used for setup:

Yes will bring the user to the standard LAS import process (see: Bulk Well Log Import)

The setup and import process is now complete and the survey, with initial data, is ready for use.
