4.1.2.7 Scan SEG-Y file(s)

Using the SEG-Y Import Wizard, this survey setup method takes the necessary data directly from the SEG-Y file(s) to set up the survey parameters.

Note that multiple SEG-Y files may be used to setup a survey using the wildcard symbol * (see: SEG-Y Wizard for details)

On clicking Next, the user is taken directly to the OS browser to select the SEG-Yfile(s) and the necessary data is automatically extracted into the relevant fields:

The user has the option to edit these fields just as in the case of a regular SEG-Y import. The difference being that here the data is not directly imported and clicking OK populates the survey setup UI. There is also a reminder to fully scan the SEG-Y(s) if this step is overlooked:

Following the OK in the extraction UI, the survey setup UI comes to the fore, showing the proposed setup:

Clicking OKfinalizes this setup process, entering the new survey into the current data root:

Pressing Select offers the user the option to immediately import the SEG-Y(s) used for setup (or not):

Choosing Yes pops up the SEG-Y import window, and the standard SEG-Y import process can then be followed (see: Import Window)

The setup and import process is now complete and the survey, with initial data, is ready for use.
