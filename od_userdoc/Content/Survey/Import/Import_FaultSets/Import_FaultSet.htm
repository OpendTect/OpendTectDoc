4.3.6.1 Import FaultSet

Select the input Ascii file. You may display the input file by pressing the Examine button. The input file should be column sorted with one point per record (line).

The main work is to specify the type of data, the presence of a file header, and the file format definition.

Predefined and saved formats are available by pressing the icon. Otherwise the format must be manually specified. The Define button gives access to the format definition window.

You must specify in the format definition the column numbers for the fault name, position; in terms of an X-Y pair, point column, a stick index (0 = no stick index). The choices of Z units offered in the Format Definition UI will reflect the Z-unit choice in the main import UI (Time or Depth). Reading may be stopped at a specific line by providing the adequate keyword.

If Coordinate Reference System (CRS) is defined for the survey, CRS conversion will be available in the import window.

It is recommended to save the format definition for a later use and QC, by clicking on the icon . Inthe pop-up window, write the name of the format and store it. The format can be stored at different levels (All surveys, Current survey, Current OpendTect user level). Press OK after having provided the name of the fault to be imported.
